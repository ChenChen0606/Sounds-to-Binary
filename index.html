Explain It

1. How does the app change a sound wave into binary?
Step 1: it samples the wave, which means it measures the wave's height at equal time steps. Step 2: it quantizes each height by rounding it to the nearest level. Step 3: it writes each level in binary using the chosen number of bits, with zeros added in front.

2. Test A with 2 bits vs 6 bits: which gives more detail?
6 bits gives more detail because it has 64 levels while 2 bits has only 4, so the binary follows the wave's real height much more closely. The trade-off is that it uses more bits (more file size).

3. Which test has the longest wavelength? How is it connected to frequency?
Test B (200 Hz) has the longest wavelength, 1.72 m. Wavelength = 343 ÷ frequency, so a higher frequency means a shorter wavelength and a lower frequency means a longer one.

4. What was the hardest stage and how did I fix it?
The hardest part was Stage 4 (binary), because the rounding sometimes went the wrong way when a value was exactly halfway between two levels, and the binary needed leading zeros. I fixed it by adding a tiny correction before rounding so halves always round up, and by using padStart to fill the zeros.
